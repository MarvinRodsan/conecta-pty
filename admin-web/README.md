# admin-web (pospuesto)

Panel React + TypeScript para revisar, aprobar y revertir importaciones de datos.

Pospuesto según ADR-001: en el MVP los datos se cargan con `data-platform` y el importador del backend, que ya guarda el historial en `importacion_datos`. Se retoma cuando haya más de una fuente de datos o más de una persona cargándolos.
